# new-progect
This document serves as the Requirements Specification for the Structured Document Intelligent Parsing System. It defines the system positioning, business boundaries, role permissions, five-layer technical architecture, primary business workflow, 12 major modules M1–M12 with a total of 92 functional requirements, and the complete data model. 

The live ParseOne demo site is served by GitHub Pages: https://2990297013a-sys.github.io/new-progect/
