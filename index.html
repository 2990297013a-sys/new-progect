Token Efficiency

解析完还不够，还要把送进模型的 token 省下来

页眉页脚、重复表头、水印和散乱空白都会占用上下文窗口。ParseOne 在结构化之后做精简输出与语义切片，让 RAG / Agent 只读真正有用的内容。

✂
自动剔除版式噪音页眉、页脚、页码、水印和装饰线在输出前丢弃，不进入模型上下文。
☰
紧凑 Markdown / JSON合并单元格还原为规范表格，去掉重复表头与多余空行，同样一份表少占一截 token。
▣
语义切片，按需检索按标题层级和语义边界切分，检索时只注入相关 chunk，避免整本手册塞进一次请求。
🎯
可设 token 预算API 支持 token_budget 与 compact 开关，按下游模型窗口自动压缩或截取，结果仍可回溯原文。

  -H "Authorization: Bearer $PARSEONE_API_KEY" \

  -F 'options={
        "output": ["markdown","json"],
        "compact": true,              // 精简输出，节省 token

        "table_mode": "restore",
        "cross_page_table": true,
        "formula": "latex",
        "chunk": { "strategy": "semantic", "size": 512, "token_budget": 800 }
      }' \

Open API

REST 风格 · OpenAPI 3.1 规范 · SDK 覆盖 Python / Node / Java / Go · 私有化镜像 30 分钟完成部署。

  • ✓POST /v3/documents/parse — 同步解析，Markdown / JSON 双输出，元素级 bbox 坐标绑定
  • ✓POST /v3/tasks — 批量任务中心：优先级调度、失败重试、死信队列、任务级进度查询
  • ✓POST /v3/chunks — 语义切片：层级切片 + token_budget，只把相关片段送给模型，节省上下文
